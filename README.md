# Description

Alloy Cape is an enterprise document security platform that solves a problem traditional watermarking can't: identifying exactly who leaked a confidential document after the fact. When an administrator issues a document, the platform generates a unique cryptographic "DNA" identity for every recipient and embeds it invisibly into their specific copy before encrypting and watermarking it. Every subsequent interaction — downloads, email shares, cloud uploads, external access, and password reveals — is logged as a timestamped forensic event.

If a document surfaces where it shouldn't, an investigator uploads the suspect file. Alloy Cape extracts its embedded DNA, matches it against the registry to identify the exact recipient copy, and runs a rule-based forensic engine that performs tamper detection, leak-probability scoring, and behavioral risk analysis — all computed deterministically from cryptographic hashes and logged activity. Only after these values are finalized does a Gemini-powered AI layer interpret them, generating a natural-language executive summary, technical assessment, and actionable recommendations for the security team. The AI is explicitly constrained to explain the verified findings, never to alter or generate the underlying risk scores itself — keeping the actual forensic verdict fully deterministic and auditable while using AI to make the results accessible to non-technical stakeholders.
